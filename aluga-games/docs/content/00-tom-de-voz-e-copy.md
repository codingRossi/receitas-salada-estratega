# 00 - Tom de Voz e Copy

Este documento orienta textos do site público, admin e mensagens de WhatsApp.

## 1. Posicionamento

A AlugaGames deve comunicar:

- locação de brinquedos, games e atrações para eventos;
- foco em eventos corporativos e experiências presenciais;
- atendimento consultivo;
- operação profissional;
- segurança, montagem e suporte;
- visual premium, claro e confiável.

Não comunicar como loja virtual.

## 2. Tom

O tom deve ser:

- profissional;
- claro;
- consultivo;
- direto;
- confiante;
- premium sem exagero;
- orientado a eventos e resultados.

Evitar:

- linguagem infantilizada;
- excesso de humor;
- urgência agressiva;
- promessas absolutas;
- tom de marketplace;
- tom de e-commerce promocional.

Não usar na UI pública como ação do visitante:

```txt

```

Esses termos podem aparecer apenas em documentos de auditoria ou listas explícitas de "não usar".

## 6. Mensagens de WhatsApp

Mensagem geral:

```txt
Olá, vim pelo site da AlugaGames e gostaria de solicitar uma proposta para um evento.
```

Produto específico:

```txt
Olá, vim pelo site da AlugaGames e gostaria de saber mais sobre: {productName}.
```

Lista de produtos:

```txt
Olá, vim pelo site da AlugaGames e gostaria de solicitar uma proposta para estes produtos: {productList}.
```

Fotografia:

```txt
Olá, vi a página de fotografia da AlugaGames e gostaria de conversar sobre uma solução para meu evento.
```

Trabalhe Conosco:

```txt
Olá, vim pelo site da AlugaGames e gostaria de falar sobre oportunidades de trabalho/parceria.
```

Regras:

- não prometer preço automático;
- não dizer que o pedido foi fechado;
- não sugerir pagamento pelo site;
- manter mensagem curta e editável no admin quando previsto.

## 7. Produtos sem preço público

Não escrever:

```txt
R$ 0,00
Consulte o preço no checkout
Preço sob consulta no carrinho
Comprar para ver preço
```

Preferir:

```txt
Solicite uma proposta pelo WhatsApp.
Converse com a AlugaGames para montar a melhor solução para seu evento.
Valores variam conforme data, local, estrutura e combinação de atrações.
```

## 8. FAQ

Perguntas recomendadas:

- Como funciona a contratação?
- A AlugaGames atende eventos corporativos?
- Posso combinar várias atrações no mesmo evento?
- O atendimento continua pelo WhatsApp?
- Os produtos têm preço fixo?
- A equipe faz montagem e suporte?

Resposta sobre preço:

```txt
Os valores dependem da data, local, estrutura necessária e combinação de atrações. Por isso, a AlugaGames atende pelo WhatsApp para entender o evento e montar uma proposta adequada.
```

Resposta sobre contratação:

```txt
Você escolhe as atrações de interesse e fala com a AlugaGames pelo WhatsApp. A equipe entende o evento, confirma disponibilidade, estrutura e detalhes operacionais antes de fechar a proposta.
```

## 10. SEO

Direção de título:

```txt
AlugaGames - Locação de brinquedos, games e atrações para eventos
```

Direção de description:

```txt
Conheça atrações, games e soluções para eventos corporativos e festas. Fale com a AlugaGames pelo WhatsApp e solicite uma proposta personalizada.
```

Regras:

- não usar "loja online";
- não usar "comprar";
- priorizar "locação", "eventos", "atrações" e "soluções".

## 11. Checklist de copy

- O texto deixa claro que a conversão é pelo WhatsApp?
- Não há promessa de compra ou pagamento online?
- Não há preço público?
- A linguagem parece premium/profissional?
- O CTA é direto?
- O texto cabe no layout responsivo?
- Termos proibidos aparecem apenas como exemplo negativo?
